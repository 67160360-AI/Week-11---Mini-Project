# Dashboard Storytelling - FurniAI

## Narrative
**จากข้อมูลคำสั่งซื้อ -> ค้นหากลุ่มลูกค้าหลัก -> หา channel หลัก -> วัด AI impact -> ตัดสินใจ**

### Slide / Pitch sequence
1. **Problem**: ลูกค้าเลือกเฟอร์นิเจอร์ให้พอดีกับพื้นที่/สไตล์ได้ยาก
2. **Solution**: FurniAI ใช้ AI วิเคราะห์พื้นที่ แนะนำเฟอร์นิเจอร์ และจำลองการจัดวาง
3. **Business question**: ลูกค้ากลุ่มไหนสร้างรายได้? ช่องทางไหนสำคัญ? AI เพิ่มมูลค่าหรือไม่?
4. **Dashboard evidence**: ใช้ KPI + รายได้ตาม Segment/Channel/Product + AI AOV + Satisfaction
5. **Action**: โฟกัสกลุ่มรายได้สูงสุด, ขยาย AI Design/AR ใน channel ที่เด่น, ใช้ Membership/CRM เพื่อเพิ่มการซื้อซ้ำ

## KPI definitions
- **Revenue** = Merchandise + Service Fee + Shipping Fee
- **AOV** = Revenue / Orders
- **AI Adoption** = Orders with AI_Assisted = Yes / All Orders
- **AR Adoption** = Orders with AR_Used = Yes / All Orders
- **Repeat Rate** = Repeat_Customer = Yes / All Orders

## What the dashboard is designed to answer
- **Who?** กลุ่มลูกค้าหลัก
- **What?** หมวดสินค้าที่สร้างรายได้
- **Where?** ช่องทางการขาย
- **Why?** AI ช่วยเพิ่ม AOV และความพึงพอใจหรือไม่
- **What next?** ควรลงทุน/ทำแคมเปญตรงไหน

## Important note
