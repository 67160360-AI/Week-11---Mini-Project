# FurniAI Storytelling Dashboard

## Project
**FurniAI - AI Furniture Ecosystem**
Business Idea Creation: Storytelling Dashboard

## What is included
- `index.html` - interactive dashboard (เปิดใน Browser ได้ทันที)
- `dashboard.html` - ไฟล์ dashboard หลัก
- `data/furniai_orders_2026.csv` - ข้อมูลธุรกรรมที่ใช้ใน dashboard
- `data/furniai_customers.csv` - ข้อมูลลูกค้า
- `data/furniai_products.csv` - ข้อมูลหมวดสินค้า
- `data/data_dictionary.csv` - คำอธิบายฟิลด์ข้อมูล
- `data/team_members.csv` - รายชื่อกลุ่มตามเอกสารอ้างอิง
- `docs/dashboard_story.md` - Storytelling / Insight / วิธีนำเสนอ
- `docs/reference/กลุ่มอุตสาหกรรมเฟอร์นิเจอร์_Reference.pdf` - PDF ที่ผู้ใช้ให้มา (เก็บเป็น reference)

## Dataset note
ข้อมูลธุรกรรมใน `furniai_orders_2026.csv` เป็น **Synthetic / Demo Data** ที่สร้างขึ้นเพื่อให้ทำ dashboard ได้ครบและสาธิตแนวคิดธุรกิจ ไม่ใช่ข้อมูลยอดขายจริงของบริษัท

## How to run
1. เปิด `index.html` ด้วย Chrome / Edge
2. ใช้ตัวกรอง Customer Segment, Sales Channel และ AI Assisted
3. Dashboard จะอัปเดต KPI และกราฟอัตโนมัติ

## Storytelling flow
1. Executive Story: รายได้รวมและบทบาทของ AI
2. Customer: กลุ่มลูกค้าที่สร้างรายได้
3. Product: หมวดสินค้าที่เด่น
4. Channel: ช่องทางที่ทำเงิน
5. AI Impact: เปรียบเทียบ AOV / Satisfaction ของการใช้ AI
6. Customer Experience: ความพึงพอใจ / การซื้อซ้ำ
7. Decision: ข้อเสนอการดำเนินงาน

## Basis from provided reference
แนวคิดถูกจัดโครงให้สอดคล้องกับ BMC ของโครงการ: Customer Segments ได้แก่ เจ้าของบ้าน, ผู้พักอาศัยในคอนโด, ผู้สร้าง/รีโนเวทบ้าน, นักออกแบบภายใน, บริษัทและสำนักงาน, โรงแรม/คาเฟ่/ร้านอาหาร; Value Proposition เน้น AI วิเคราะห์ห้อง แนะนำเฟอร์นิเจอร์ จำลองการจัดวาง และเพิ่มความมั่นใจก่อนซื้อ; Channels มีเว็บไซต์/แอป AI, Social Media, Smart Showroom, Marketplace และพันธมิตร/งานแสดงสินค้า
